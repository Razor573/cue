# Cue Companion Chrome Extension

A discreet browser extension that pairs with the **Cue** desktop AI assistant to capture web page DOM and active selections directly into prompt context.

## Installation in Chrome / Chromium

1. Open Chrome and navigate to `chrome://extensions/`.
2. Toggle **Developer mode** in the top right corner.
3. Click the **Load unpacked** button.
4. Select this directory (`cue/companion-extension`).
5. Pin **Cue Companion** to your Chrome toolbar.

## Pairing with Cue Desktop

1. Launch Cue on your desktop.
2. In Cue, open **Settings** (`Ctrl+,`) and switch to the **Companion** tab.
3. Click **Connect** to open the 60-second pairing window.
4. Click the Cue Companion extension icon in Chrome and click **Pair with Cue**.
5. Once paired, click **Capture this page** anytime, or use Cue's prompt hotkey to incorporate the extracted web page context.
